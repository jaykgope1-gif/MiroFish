# MiroFish God View

A multi-agent simulation of how a market reacts, with a live operator console
at `/god`. Built on [MiroFish](https://github.com/666ghj/MiroFish).

Source code of this modified version (AGPL-3.0):
https://github.com/jaykgope1-gif/MiroFish

The agents are AI role-players. Their reactions help find objections and test
wording; they do not predict what real people will do.
